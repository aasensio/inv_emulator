# `invert_caii8542.py`: Ca II 8542 (SST/CRISP)

This script applies the same machinery to a chromospheric line observed with
a Fabry–Pérot instrument. It shows how to handle sparse wavelength sampling,
an instrumental transmission profile, absolute intensity units and a
per-pixel μ.

## Forward model

```python
wave_syn = 8539.8357 + 0.03 * np.arange(150)       # emulator grid
lines = [LineEmulator("weights/emulator_caii8542_pca_resmlp512_cosine_deriv.pt", wave_syn)]

fpi_8542 = pyFPI.CRISP(8542.0, version=1, nrays_hr=11, nrays_lr=11, verbose=False)
tr_8542 = fpi_8542.dual_fpi_full_complex(wave_syn - 8542.0, ech=0.0, erh=-0.008, normalize_tr=True)
synthesizer = SpectralSynthesizer(lines, psf=(wave_syn - LAMBDA_8542, tr_8542))
```

The CRISP transmission profile is passed as a `(dlambda, profile)` PSF. The
emulator output is convolved with it on the 0.03 Å grid and then sampled at
the 15 observed tunings. `pyFPI` is the compiled module
`pyFPI.cpython-313-x86_64-linux-gnu.so` in the repository root.

## Variables

Ca II 8542 forms over a much larger height range, so more nodes are used:

```python
REG_STRENGTH = 0.5
nodes = {
    "T":    [-7.5, -5.5, -4.0, -2.5, -1.0, 0.0, 1.5],
    "vz":   [-7.5, -4.0, 1.5],
    "vmic": [-7.5, 1.5],
    "Bx":   [-7.5, 1.5], "By": [-7.5, 1.5], "Bz": [-7.5, 1.5],
}
variables = {
    "T":  VariableConfig(nodes["T"], 500.0, training_bounds("T", nodes["T"]), smooth(100.)),
    "vz": VariableConfig(nodes["vz"], 1.0, (-20.0, 20.0)),
    "vmic": VariableConfig(nodes["vmic"], 0.5, (0.0, 3.4)),
    "Bx": VariableConfig(nodes["Bx"], 200.0, training_bounds("Bx", nodes["Bx"])),
    "By": VariableConfig(nodes["By"], 200.0, training_bounds("By", nodes["By"])),
    "Bz": VariableConfig(nodes["Bz"], 200.0, training_bounds("Bz", nodes["Bz"]), smooth(200.)),
}
transverse_regularization = [TransverseRegularizer("Bx", "By", smooth(100.0))]
```

`noise={"I": 1e-2, "Q": 2.5e-3, "U": 2e-3, "V": 2e-3}` (in units of
$I_\mathrm{norm}$), `chunk_size=65536*4`, 500 iterations.

## Observations and μ

The CRISP cube (`y, x, Stokes, scan, wavelength` in W m⁻² Hz⁻¹ sr⁻¹) is
cropped to `X_RANGE`, `Y_RANGE` and divided by `I_NORM_SI = 2.59e-8`, the
emulator's intensity unit. Wavelengths and helioprojective coordinates come
from the `WCS-TAB` extension, and

$$
\mu = \sqrt{1 - \frac{x^2 + y^2}{R_\odot^2}}
$$

is computed for every pixel (`RSUN_ARCSEC = 945`).

## Initial guess

The weak field and centre of gravity of Ca II 8542 (²D₅/₂ – ²P₃/₂), within
±0.6 Å of the line centre.
