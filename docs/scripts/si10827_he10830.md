# `invert_si10827_he10830.py`: Si I 10827 + He I 10830

This script runs a joint inversion of the photosphere (Si I 10827 emulator),
one or more He I 10830 chromospheric slabs (He I PCA emulator plus the exact
slab formal solution), and a telluric line at 10832 Å. All photospheric
nodes, slab parameters and telluric parameters are inverted together, with
L2 spatial smoothing of every map. The configured data set is a 447×170
pixel 10830 Å map normalized to the quiet-Sun continuum.

## Top-level settings

```python
observations_file = 'observations/stokesall_15Jul24ARM1_009_norm.h5'
output = 'inversions/inversion_result_si10827_he10830.h5'
HE_HEIGHT = 3.0               # arcsec, fixed
HE_PREFIXES = ("He1_", "He2_")   # slabs from the photosphere outwards; ("He_",) for a single slab
TELLURIC = 10832.0            # A, reference wavelength of the telluric line (None: no telluric line)
```

## Forward model

```python
wave_si = np.linspace(10824.0, 10833.0, 350)
photosphere = SpectralSynthesizer([LineEmulator("weights/emulator_si10827_pca_resmlp512_cosine_deriv.pt", wave_si)])
chromosphere = HeIPCAEmulator.load("weights/emulator_he10830_pca.pt")
synthesizer = SiHeSynthesizer(photosphere, chromosphere, step=0.02, psf=None, pumping="boundary",
                              telluric=TELLURIC, prefix=HE_PREFIXES)
```

1. The Si I emulator gives the photospheric spectrum on 350 points. It is
   Doppler-shifted by $v_\mathrm{ref}$ and interpolated with a cubic
   spline to a 0.02 Å grid.
2. `He1_` is illuminated by the Si I spectrum, and `He2_` by the spectrum
   emerging from `He1_`. Each slab has its own field, $\tau$, velocity,
   Doppler width and damping.
3. The pumping radiation of each slab follows its boundary intensity
   (`pumping="boundary"`), as in Hazel2.
4. A Voigt telluric line (`Tel_shift`, `Tel_width`, `Tel_depth`, `Tel_a`)
   multiplies Stokes I.

## Photospheric variables

```python
nodes = {
    "T":    [-7.5, -4.0, -2.5, -1.0, 1.5],
    "vz":   [-7.5, 1.5],
    "vmic": [-1.0],
    "Bx":   [-7.5, 1.5],
    "By":   [-7.5, 1.5],
    "Bz":   [-7.5, 1.5],
}
variables = {
    "T":    VariableConfig(nodes["T"],    500.0, training_bounds("T", nodes["T"]),   smooth(100.0)),  # K
    "vz":   VariableConfig(nodes["vz"],   1.0,   (-20.0, 20.0),                      smooth(0.5)),    # km/s
    "vmic": VariableConfig(nodes["vmic"], 0.5,   (0.0, 3.4),                         smooth(0.2)),    # km/s
    "Bx":   VariableConfig(nodes["Bx"],   200.0, training_bounds("Bx", nodes["Bx"]), smooth(50.0)),   # G
    "By":   VariableConfig(nodes["By"],   200.0, training_bounds("By", nodes["By"]), smooth(50.0)),   # G
    "Bz":   VariableConfig(nodes["Bz"],   200.0, training_bounds("Bz", nodes["Bz"]), smooth([30.0, 50.0])),
}
```

The `Bz` regularization has **one jump per node** (30 G at the bottom node,
50 G at the top node), so the two heights are smoothed differently.

## He I slab variables

```python
for p in HE_PREFIXES:
    vleft, vright = (-20.0, 5.0) if p == "He1_" else (-5.0, 40.0)
    variables |= {
        p + "Bx":     slab_variable(100.0, (0.0, 1500.0),    smooth(50.0)),   # G, vertical frame
        p + "By":     slab_variable(100.0, (-1500.0, 1500.0), smooth(50.0)),
        p + "Bz":     slab_variable(100.0, (-1500.0, 1500.0), smooth(50.0)),
        p + "tau":    slab_variable(0.3,   (0.01, 5.0),       smooth(0.1)),
        p + "v":      slab_variable(1.0,   (vleft, vright),   smooth(0.5)),   # km/s
        p + "deltav": slab_variable(1.0,   (4.0, 18.0),       smooth(0.5)),   # km/s
        p + "a":      slab_variable(0.1,   (0.0, 1.5),        smooth(0.05)),
        p + "beta":   slab_variable(0.1,   (0.0, 5.0), fixed=True),
        p + "height": slab_variable(0.5,   (0.1, 10.0), fixed=True),
    }
```

* The **velocity windows** separate the two components. `He1_` covers
  upflows and slow downflows (−20 to 5 km/s), and `He2_` covers fast
  downflows (−5 to 40 km/s). This avoids the label-switching degeneracy of
  two identical slabs.
* The bounds of $\Delta v$ and $a$ keep the slab inside the
  emulator's training range.
* `beta` (the source-function factor) and `height` are fixed. Set
  `fixed=False` to invert them.

## Telluric variables

```python
variables |= {
    "Tel_shift": slab_variable(0.01, (-0.3, 0.3),   smooth(0.5)),    # A, lambda0 = TELLURIC + Tel_shift
    "Tel_width": slab_variable(0.01, (0.005, 0.3),  smooth(0.5)),    # A
    "Tel_depth": slab_variable(0.05, (0.0, 1.0),    smooth(0.2)),
    "Tel_a":     slab_variable(0.1,  (0.0, 2.0),    smooth(0.5)),
}
```

## Optimizer

```python
config = InversionConfig(
    variables=variables,
    stokes_weights={"I": 1.0, "Q": 2.0, "U": 2.0, "V": 1.0},       # Q, U up-weighted
    noise={"I": 7.2e-3, "Q": 1.6e-3, "U": 1.5e-3, "V": 2.9e-3},
    optimizer="adam", lr=0.1, lr_final_fraction=0.05, n_iter=500,
    chunk_size=1024, log_every=5,
)
```

`chunk_size=1024` is much smaller than for Fe I, because the slab synthesis
on a 0.02 Å grid with two slabs needs much more memory per pixel.

## Initial guess

```python
# photosphere: weak field and centre of gravity of Si I (3P2 - 3P2, gbar = 1.5, Gbar = 2.25)
g_si = lande_factor(J=2, L=1, S=1)
wfa_si = WeakFieldConfig(lines=[WeakFieldLine(lambda0=LAMBDA_SI, geff=effective_lande(g_si, g_si, 2, 2),
                                              Geff=second_order_lande(g_si, g_si, 2, 2),
                                              wave_range=(LAMBDA_SI - 0.5, LAMBDA_SI + 0.5))],
                         linear_polarization_sign=-1.0)
init = initial_guess(observations, wave_obs, config, logtau, mean_strat, wfa=wfa_si,
                     cog_lines=[(LAMBDA_SI, 0.25)])

# He I: velocity, tau and weak field of the red component; tau split between the slabs,
# velocities offset by -2 / +2 km/s
init |= he_slabs_initial_guess(observations, wave_obs, mu_map, prefixes=HE_PREFIXES, height=HE_HEIGHT)

# telluric: position and depth of the I minimum within 0.3 A of 10832 A
...
init["Tel_width"][:] = 0.04
init["Tel_a"][:] = 0.5
```

For He I the Q/U sign follows the textbook convention (+1), unlike the SIR
convention of the photosphere. The effective Landé factor of the red blend
(1.13) was calibrated on Hazel2 syntheses. The field is estimated in the LOS
frame and rotated to the vertical frame with μ.

## Output

Besides the photospheric `nodes/T`, ... and `stratification/...`, the file
has `nodes/He1_Bx`, ..., `nodes/He2_height` and `nodes/Tel_*` (each
`(nx, ny, 1)`). The telluric line centre is `TELLURIC + Tel_shift`.

## Variant: `invert_si10827_he10830_l1.py`

This variant runs the same inversion on cross-talk-corrected data
(`..._norm_xtalk.h5`). Its configuration favours a **sparse second
component** and an ambiguity-aware transverse field:

| Setting | `invert_si10827_he10830.py` | `invert_si10827_he10830_l1.py` |
|---------|------------------------------|--------------------------------|
| `T` nodes | −7.5, −4, −2.5, −1, 1.5 | −7.5, −4, −2.5, −1, **0**, 1.5 |
| `Bx`, `By` nodes | −7.5, 1.5 | **−1.0** (constant) |
| photospheric (Bx, By) regularization | `smooth(50)` each | `TransverseRegularizer("Bx", "By", smooth(20))` |
| slab (Bx, By) regularization | `smooth(50)` each | `TransverseRegularizer(p+"Bx", p+"By", smooth(20))` per slab |
| `Bz` | `smooth([30, 50])` | `smooth(50)` |
| `He1_v` / `He2_v` | (−20, 5) / (−5, 40) | (−40, 40) / **(15, 40)** |
| `He*_deltav`, `He*_a` bounds | (4, 18), (0, 1.5) | (4, **10**), (0, **0.2**) |
| `He1_tau` regularization | `smooth(0.1)` | none |
| `He2_tau` regularization | `smooth(0.1)` | **`Regularizer("l1", 1 / 0.03**2)`** |
| `v`, `deltav`, `a`, telluric regularization | L2 | none |

The L1 penalty on `He2_tau` acts as a soft threshold. It drives the
fast-downflow component to $\tau\to$ its lower bound wherever the data do
not need it, so the second component appears only in the pixels that really
show a redshifted signal. The weight $1/0.03^2\approx1100$ means each
unit of `He2_tau` costs about 1100 units of $\chi^2$ per pixel. For
example, $\tau=0.03$ costs about 33, roughly half the noise fluctuation of
$\chi^2$ per pixel.
