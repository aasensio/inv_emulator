# `invert_fe6301_6302.py`: Fe I 6301.5 + 6302.5

This script inverts Hinode SP observations of the Fe I doublet with the two
Fe I PCA emulators. The configured data set is a 400×400 pixel crop of
AR 11967.

## Forward model

```python
LAMBDA_6301, LAMBDA_6302 = 6301.5012, 6302.4936
wave_syn = np.linspace(6300.8921, 6303.2671, 150)         # Hazel synthesis grid
lines = [
    LineEmulator("weights/emulator_fe6301_pca_resmlp512_cosine_deriv.pt", wave_syn[wave_syn - LAMBDA_6301 < 0.5]),
    LineEmulator("weights/emulator_fe6302_pca_resmlp512_cosine_deriv.pt", wave_syn[wave_syn - LAMBDA_6302 > -0.5]),
]
psf = None                                                 # or {"fwhm": 0.03} / (dlambda, profile)
synthesizer = SpectralSynthesizer(lines, psf=psf)
```

The two emulators split the 150-point grid at $\lambda-\lambda_{6301}=0.5$ Å,
in the continuum between the lines, into 70 and 80 points. The synthesizer
concatenates them back. The observed Hinode wavelengths
(`wavelength_Hinode.txt`) are reached by Doppler shift and linear
interpolation.

## Nodes and variables

```python
nodes = {
    "T":    [-7.5, -4.0, -2.5, -1.0, 0.0, 1.5],     # 6 nodes, cubic
    "vz":   [-7.5, 1.5],                            # linear: absolute velocity + gradient
    "vmic": [-1.0],                                 # constant
    "Bx":   [-7.5, 1.5],
    "By":   [-7.5, 1.5],
    "Bz":   [-7.5, 1.5],
}
REG_STRENGTH = 5.0
variables = {
    "T":    VariableConfig(nodes["T"],    scale=500.0, bounds=training_bounds("T", nodes["T"]),   regularization=smooth(20.0)),
    "vz":   VariableConfig(nodes["vz"],   scale=1.0,   bounds=(-20.0, 20.0),                      regularization=smooth(0.1)),
    "vmic": VariableConfig(nodes["vmic"], scale=0.5,   bounds=(0.0, 3.4),                         regularization=smooth(0.1)),
    "Bx":   VariableConfig(nodes["Bx"],   scale=200.0, bounds=training_bounds("Bx", nodes["Bx"])),
    "By":   VariableConfig(nodes["By"],   scale=200.0, bounds=training_bounds("By", nodes["By"])),
    "Bz":   VariableConfig(nodes["Bz"],   scale=200.0, bounds=training_bounds("Bz", nodes["Bz"]), regularization=smooth(100.)),
}
transverse_regularization = [TransverseRegularizer("Bx", "By", smooth(100.0))]
```

* **Temperature.** Six nodes from the top (−7.5) to the bottom (1.5) of the
  atmosphere give a cubic interpolating B-spline. The Fe I lines constrain
  roughly $-3\lesssim\log\tau\lesssim0$. The outer nodes are held by the
  training bounds and the smoothing.
* **Velocity and field.** Two nodes give a linear stratification in
  $\log\tau$: a value at $\log\tau=-1$ (which becomes
  $v_\mathrm{ref}$ for `vz`) and a gradient.
* **Transverse field.** $B_x, B_y$ have no regularizers of their own. They
  are smoothed together through the ambiguity-invariant
  $B_t(\cos2\phi,\sin2\phi)$, with `lo_strat["Bx"] *= 0` enforcing
  $B_x\ge0$.
* **Bounds.** For `T`, `Bx`, `By` and `Bz` the bounds are the 0.1–99.9
  percentile range of the training models at each node's height, so the
  emulators never extrapolate.

## Optimizer

```python
config = InversionConfig(
    variables=variables, transverse_regularization=transverse_regularization,
    stokes_weights={"I": 1.0, "Q": 1.0, "U": 1.0, "V": 1.0},
    noise={"I": 7.2e-3, "Q": 1.6e-3, "U": 1.5e-3, "V": 2.9e-3},
    optimizer="adam", lr=0.1, lr_final_fraction=0.05, n_iter=500,
    chunk_size=65536 * 3, log_every=5,
)
```

The 160 000 pixels fit in one chunk of 196 608. With a spatial PSF this
means one pass per iteration (see [spatial PSF](../inversion.md#spatial-psf)).

## Observations

```python
with h5py.File('/scratch1/hinode/ar11967/ar11967.h5', 'r') as f:
    observations = f['stokes'][:]                         # (4, nx, ny, nl) in this file
contQS = np.median(observations[0, 0:100, 300:400, 0])    # quiet-Sun continuum
observations = np.transpose(observations, (1, 2, 0, 3))[0:400, 0:400] / contQS
wave_obs = np.loadtxt('wavelength_Hinode.txt')
mu = np.ones(observations.shape[0])
```

The emulators produce intensities relative to the Hazel continuum, so the
data are normalized to a quiet-Sun patch. To read a generic HDF5 file with
datasets `stokes (nx, ny, 4, nl)`, `wavelength` (absolute Å) and `mu`, use the
commented-out block just above this one in the script.

## Initial guess

```python
g_l, g_u = lande_factor(J=2, L=1, S=2), lande_factor(J=2, L=2, S=2)              # 5P2 - 5D2
line_6301 = dict(lambda0=LAMBDA_6301, geff=effective_lande(g_u, g_l, 2, 2), Geff=second_order_lande(g_u, g_l, 2, 2))
g_l, g_u = lande_factor(J=1, L=1, S=2), lande_factor(J=0, L=2, S=2)              # 5P1 - 5D0
line_6302 = dict(lambda0=LAMBDA_6302, geff=effective_lande(g_u, g_l, 0, 1), Geff=second_order_lande(g_u, g_l, 0, 1))
split = 0.5 * (LAMBDA_6301 + LAMBDA_6302)
wfa = WeakFieldConfig(lines=[WeakFieldLine(**line_6301, wave_range=(0.0, split)),
                             WeakFieldLine(**line_6302, wave_range=(split + 1e-4, 1e5))],
                      linear_polarization_sign=-1.0)
init = initial_guess(observations, wave_obs, config, logtau, mean_strat, wfa=wfa,
                     cog_lines=[(LAMBDA_6301, 0.25), (LAMBDA_6302, 0.25)])
```

The weak-field approximation is used **only** for the starting field. The
fit itself uses the emulators.

## Spatial PSF (optional)

```python
PSF_FILE = 'psfs/hinode_psf_size_256_def_-0.32_hinodepix.fits'   # the script ships with PSF_FILE = None
PSF_SIZE = 63                 # (commented out in the script) crop: 31 -> 95 %, 63 -> 98 %, 257 -> 100 % enclosed energy
spatial_psf = None if PSF_FILE is None else SpatialPSF(load_psf(PSF_FILE), size=PSF_SIZE)
inverter = Inverter(synthesizer, config, logtau, spatial_psf=spatial_psf)
```

With a PSF, the synthetic maps are convolved with the Hinode PSF before the
comparison. The inferred maps are then deconvolved estimates of the
atmosphere. `synthetic_nopsf` in the output holds the profiles before the
convolution. The output name switches between
`inversions/inversion_result_fe6301_6302_nopsf.h5` and `..._psf.h5`.
